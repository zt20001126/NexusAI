# 修复长追问表单无法滚动

- 日期：2026-10-15
- 变更类型：缺陷修复
- 影响范围：聊天页 Agent 追问表单较长时的显示和滚动

## 背景

聊天内容容器 `.chat-content` 使用 `overflow: hidden`，而追问表单与独立的消息滚动区是同级元素。问题数量较多、表单高度超过窗口时，内容会被容器裁切，鼠标滚轮也无法滚动到后续题目。

## 变更内容

- 将聊天内容容器改为纵向可滚动，并隐藏横向溢出。
- 将聊天内容容器纳入现有的细滚动条样式。

## 涉及文件

- `frontend/src/index.css`：允许长追问表单通过聊天内容区域纵向滚动。
- `CHANGELOG.md`：登记未发布修复摘要。

## 设计决策

- 让包含消息和追问卡片的共同容器承接纵向溢出，避免仅滚动消息区而无法触达同级表单。

## 测试与验证

- 浏览器验证：Edge headless 加载使用实际 `frontend/src/index.css` 的临时页面，并渲染 12 道追问题目。
- 结果：修改前验证失败，滚动区 `overflowY=hidden`、内容高度 1416 px、可视高度 374 px；修改后通过，滚动区为 `overflowY=auto`，长表单内容仍超出可视高度并可滚动。
- 命令：`npm run build`（在 `frontend/` 目录执行）
- 结果：TypeScript 检查通过，Vite 构建成功。

## 潜在影响

- 消息区保留自身滚动；表单溢出时外层聊天内容区负责滚动。
