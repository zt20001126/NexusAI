# 优化图片智能体生图提示词

- 日期：2026-10-20
- 变更类型：其他
- 影响范围：图片智能体的意图分析和生图提示词整理

## 背景

用户反馈生成结果与上传参考图过于相似。现有系统提示词没有区分需要保持一致的商品外观与可以重新设计的画面元素，也没有指导模型把风格词展开成具体视觉要求。

## 变更内容

- 明确提示词整理模型只收到参考图上传状态，不会读取图片内容，不得声称识别图片细节。
- 有参考图时，要求下游生图模型保持商品可见外观一致；除非用户明确要求复刻，默认重新设计场景、背景、构图、视角、光线和装饰。
- 要求把风格偏好展开为表现方式、场景、构图、镜头、光线、色彩和质感等具体描述，并区分商品本身颜色与背景配色。
- 区分主图和详情页图的视觉重点，禁止自行编造图片文案、参数和宣传承诺。

## 涉及文件

- `backend/agents/image_agent/prompts/system.py`：补充参考图使用策略、风格展开规则及主图/详情页图提示词要求。
- `CHANGELOG.md`：更新 `[Unreleased]` 摘要。

## 设计决策

- 借鉴参考项目中“参考图约束商品实体、画面构图可变”和“按产品气质明确视觉设计细节”的提示词结构。
- 不调整生图接口或图像传递流程；提示词整理阶段继续只获得参考图是否上传这一信息。

- `git diff --check`：通过，无空白错误。

## 潜在影响

- 有参考图时，默认生成结果会更强调重新设计画面构图与场景；用户明确要求沿用参考图设计时仍按用户指定内容处理。提示词无法保证生图模型每次都产生明显差异，实际效果仍受模型对参考图的依赖程度影响。
