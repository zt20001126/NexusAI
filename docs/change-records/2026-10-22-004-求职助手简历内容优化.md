# 求职助手简历内容优化

- 日期：2026-10-22
- 变更类型：新功能
- 影响范围：求职助手图、简历应用服务与仓储、共享追问 Runner

## 背景

用户需要在求职助手中预览简历优化结果，并在明确确认后更新已保存简历。

## 变更内容

- 新增无数据库副作用的简历优化候选工具和 Checkpoint 待确认状态。
- 新增图节点：只在对应确认题卡明确选择“确认采用并保存”时调用简历写入服务；重新生成/取消清理候选。
- 简历服务限制可修改字段并校验完整简历 DTO；仓储以 `updated_at` 条件更新，避免并发覆盖。
- 求职助手追问轮数提升为 10，其他智能体保留默认 3 轮。
- 更新求职助手提示词、README、接口说明和项目变更摘要。

## 涉及文件

- `backend/agents/job_agent/`：候选工具、图节点、状态、提示词及功能说明。
- `backend/app/service/job_resume.py`、`backend/app/crud/resume.py`：候选合并、Schema 校验与条件更新。
- `backend/agent/runner.py`、`backend/bootstrap/runtime.py`：每个 Runner 可配置题卡轮数。
- `backend/tests/test_job_resume_reader.py`、`backend/tests/test_job_resume_optimization.py`：写入约束和确认门控。
- `docs/接口文档.md`、`CHANGELOG.md`：用户可见说明。

## 设计决策

- 模型只提交候选，不提供直接写库工具；确认题卡必须与待保存候选对应。
- 为避免改写事实，工作和项目只允许更新已存在条目的正文；教育经历事实保持原样。可编辑范围为求职意向、技能和工作/项目正文。
- 不新增数据库表、HTTP API 或迁移；Checkpoint 仅在等待确认时保存候选。
