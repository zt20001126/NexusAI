# 实习僧 API 环境配置

- 日期：2026-10-21
- 变更类型：工程化
- 影响范围：求职智能体服务端配置与本地启动环境

## 背景

求职智能体准备申请并接入实习僧开放平台，需要为平台商户凭证和调用参数提供服务端配置入口。

## 变更内容

- 在集中配置中新增实习僧 `APP_ID`、`APP_SECRET`、API 基础地址和请求超时设置。
- 将配置变量加入 `.env.example`，并补充后端环境变量读取测试。
- 在 README 说明凭证获批后填写的位置，并明确当前只预留配置，尚未接入搜索调用。

## 涉及文件

- `backend/infra/settings.py`：集中读取实习僧凭证、API 地址和超时。
- `backend/.env.example`、`backend/.env`：添加凭证占位与默认调用参数；实际凭证留空。
- `backend/tests/test_settings.py`：验证环境变量别名、SecretStr 和安全默认值。
- `README.md`、`CHANGELOG.md`：说明配置用途与当前集成状态。

## 设计决策

- `APP_ID` 和 `APP_SECRET` 使用 `SecretStr`，仅供后端签名使用；API 地址和请求超时保留可配置性。
- 不将凭证写入 Compose 单独环境映射；后端和 Worker 已共同读取 `backend/.env`。

## 测试与验证

- 命令：`backend/.venv/Scripts/python.exe -m pytest -q tests/test_settings.py`
- 结果：8 通过，1 条第三方 Starlette 弃用警告。
- 命令：在 `backend/` 中通过 `AppSettings()` 读取 `.env` 并断言实习僧配置值。
- 结果：通过；凭证为空，默认 API 地址和超时均正确加载，未输出任何凭证值。
- 命令：`git diff --check`
- 结果：通过。

## 潜在影响

- 新配置默认凭证为空，不影响现有服务启动；获得商户凭证并实现 API 调用后才会生效。

## 后续事项

- 实习僧审核通过后，将真实凭证填写到本地或部署环境的 `SHIXISENG_APP_ID`、`SHIXISENG_APP_SECRET`，并在平台登记服务端出口 IP。
- 后续实现职位搜索客户端时复用上述配置。
