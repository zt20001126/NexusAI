# 简历技能数据格式迁移

- 日期：2026-10-20
- 变更类型：数据迁移
- 影响范围：`resumes.content.skills` JSONB 字段及现有简历读取

## 背景

专业技能编辑器和 API 契约已改为单份 Tiptap 文档，但当前 Compose 数据库仍有旧版字符串数组记录。读取兼容逻辑可以转换响应，却不会回写数据库。

## 变更内容

- 新增迁移，将技能字符串数组按原顺序转换为 Tiptap 段落文档；空数组转换为空段落。
- 迁移前校验最多 20 项、每项不超过 500 字且元素均为字符串；异常数据会中止并回滚。
- 在当前 Compose PostgreSQL 数据库执行迁移；`updated_at` 保持不变。
- 迁移前备份 `resumes` 表，并更新数据库文档与 `[Unreleased]`。

## 涉及文件

- `backend/migrations/015_resume_skills_tiptap.sql`：新增事务化、可重复执行的 JSONB 数据迁移。
- `docs/数据库文档.md`：说明迁移顺序、格式与当前数据库状态。
- `CHANGELOG.md`：记录用户可见的数据格式调整。

## 设计决策

- 保留 `ResumeContent` 中的旧格式转换器，继续兼容其他数据库尚未迁移的旧记录及旧版客户端。当前数据库完成回填不代表所有部署环境和客户端都已升级。
- 备份保存于 `C:\Users\96598\AppData\Local\Temp\nexusai-resumes-before-015-20261020.dump`。
