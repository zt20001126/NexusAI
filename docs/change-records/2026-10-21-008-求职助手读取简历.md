# 求职助手读取已保存简历

- 日期：2026-10-21
- 变更类型：新功能
- 影响范围：求职助手工具、运行时依赖注入、提示词与相关文档

## 背景

用户希望求职助手能够访问数据库中已保存的简历内容。本次沿用当前固定主体 `nexusai-resume-owner`，只增加工具能力，不定义模型调用工具的触发场景。

## 变更内容

- 新增只读、无模型参数的 `read_saved_resume` 工具，并从生产运行时注入固定主体简历读取器。
- 将数据库记录校验并投影为求职事实，仅返回求职意向、手动填写的工作年限、教育、技能、工作和项目经历；富文本转换为纯文本并应用共享文本上限。
- 排除姓名、电话、邮箱、年龄、照片标识、照片字节与版式配置；无记录和读取失败分别返回 `not_found` 与受控 `unavailable` 状态。
- 更新求职助手提示词和接口/Agent 文档，声明读取边界、简历内容按不可信用户数据处理，以及固定主体仅适用于可信私有部署。
- 增加读取器字段/失败/截断测试及 Agent 工具调用测试。

## 设计决策

- 工具不接受主体 ID、简历 ID 或查询条件，读取主体在服务端固定绑定。
- 复用 `PostgresResumeRepository.get`，不经过会清理照片的应用服务，也不修改 API、数据库结构或保存流程。
- 对简历 JSONB 做现有简历契约校验；数据不合法时按不可用处理，不把简历正文或数据库异常详情写入日志或工具错误。
- 固定主体仍意味着访问求职聊天的用户能读取这份共享简历，因此部署范围限制为本机或可信私有网络。
