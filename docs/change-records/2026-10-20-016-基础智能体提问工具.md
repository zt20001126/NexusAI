# 基础智能体结构化提问工具

- 日期：2026-10-20
- 变更类型：新功能
- 影响范围：基础对话助手、共享 Runner 暂停识别、基座 Python 响应模型和开发说明

## 背景

基础对话助手此前没有提问工具。共享 Runner 已支持结构化题卡、等待状态和答案恢复，本次为基础助手接入该能力，使其可沿用已有聊天运行流程完成提问和恢复。

## 变更内容

- 为基础对话助手增加 `ask_user_questions` 工具；每批接受 1–3 道单选题，每题使用共享题目字段、四个选项及说明，并禁止自定义输入。
- 在基础助手提示词和工具描述中加入通用触发边界：用户明确要求题卡，或缺少会实质改变结果的关键选择时才提问；开放式澄清继续使用自然语言。
- 让基础智能体图在提问工具执行后结束当前阶段；共享 Runner 将题卡保存为消息并进入 `WAITING`，答案校验后恢复原 run。
- 扩展 `AgentResponse`，通过 `completed` 和 `waiting` 区分最终回答与待答题卡；基础工厂默认注入工具，低层 `BaseAgent` 仍只使用显式传入的工具。
- 增加工具 schema、直接调用、Runner 等待/恢复、错误答案和历史消息的自动化覆盖，并更新基座 README、方案状态和 `CHANGELOG.md`。

- `backend/agents/base_agent/factory.py`、`graph.py`、`agent.py`、`schemas.py`：接入工具、暂停路由和响应状态。
- `backend/agents/base_agent/prompts/agent.md`、`README.md`：说明触发规则、题目边界和等待恢复方式。
- `backend/tests/fake_models.py`、`test_base_agent.py`、`test_runtime.py`：新增确定性提问模型及单元、集成测试。
- `docs/implementation-plans/2026-10-20-015-基础智能体提问工具方案.md`：更新实际文件清单、验收状态和未执行的人工 UI 验收说明。
- `CHANGELOG.md`：更新 `[Unreleased]`。

## 设计决策

- 复用 `agent.schemas.question` 的共享字段与校验，通过基础工具专属 schema 将题型收窄为 `SingleChoice`，不改变其他智能体继续使用多选题的能力。
- 暂停、事件、答案校验和恢复继续由共享 Runner 负责；不新增 HTTP、SSE、前端协议、数据库字段或迁移。
- 每次运行最多三轮的限制由 Runner 按 run 元数据执行。直接 `ainvoke` 不按 Checkpoint 中整个会话的历史消息累计轮数，避免不同调用互相影响。
