# 将智能体选择器移入消息输入框

- 日期：2026-10-14
- 变更类型：界面改进
- 影响范围：聊天页智能体切换控件的位置和输入框布局

## 背景

用户希望在聊天对话框内部选择智能体，不再把选择器放在页面右上角。

## 变更内容

- 将智能体下拉框移动到消息输入框内部的底部工具栏。
- 保留切换智能体时清空当前草稿会话、待上传图片和错误提示的行为。
- 调整桌面和窄屏输入框布局，让输入区与底部工具栏保持在同一对话框内。

## 涉及文件

- `frontend/src/features/chat/ChatPage.tsx`：移除顶栏选择器并将智能体选项传给输入框。
- `frontend/src/features/chat/components/Composer.tsx`：在输入框底部工具栏渲染选择器。
- `frontend/src/index.css`：新增底部工具栏布局及响应式样式。
- `CHANGELOG.md`：记录未发布界面变化。

## 设计决策

- 复用原来的智能体列表、选择状态和切换回调，只改变控件位置。
- 下拉框放在输入区域下方，符合用户提供的界面参考。

## 测试与验证

- 命令：在 `frontend` 目录运行 `npm run build`。
- 结果：TypeScript 检查和 Vite 生产构建通过；278 个模块构建完成。
- 命令：在仓库根目录运行 `git diff --check`。
- 结果：退出码 0，无空白错误；Git 提示部分工作区文件会按配置转换 LF/CRLF。

## 潜在影响

- 输入框整体高度增加，以容纳底部智能体选择器。
