# 接入阿里云 OSS 并统一业务雪花 ID

- 日期：2026-10-14
- 变更类型：新功能 / 架构 / 数据模型
- 影响范围：图片上传和生成、任务结果持久化、所有应用业务表 ID、数据库迁移与项目文档

## 背景

图片参考图和生成结果需要长期保存；用户要求图片字节存入阿里云 OSS，业务结果继续共用 `task_results`，并把 `conversations`、`messages`、`agent_runs`、`task_results` 等业务表 ID 改为雪花数字。

## 变更内容

- 增加雪花 ID 生成器、静态智能体数据库 ID，以及认证主体到内部雪花用户 ID 的映射。
- 增加阿里云 OSS 适配器，保存参考图片和生成图片；Bucket 按私有存储使用，下载前校验用户归属。
- 将 `task_results` 调整为 `BIGINT` 业务 ID、`input_data`/`result_data` JSONB 元数据；图片字节和独立附件表不再用于新链路。
- 增加旧数据库图片转存工具和一次性 SQL 迁移；迁移旧 TEXT ID、Checkpoint 线程键，并移除旧图片字节列及附件表。
- 为 OSS 未配置和读写错误增加稳定响应，校验对外 ID 格式，并修复生成工具的参数组装。
- 更新 OSS 环境变量模板、README、架构、API、数据库说明和项目变更日志。

- `backend/agent/persistence/`、`backend/agent/runner.py`、`backend/app/`：业务 ID 持久化、OSS 使用和 API 行为。

- `backend/tests/test_aliyun_oss.py`、`backend/tests/test_api.py`、`backend/tests/test_image_agent.py`：OSS 适配和业务链路验证。
- `backend/.env.example`、`backend/requirements.txt`、`README.md`、`docs/架构说明.md`、`docs/接口说明.md`、`docs/数据库结构.md`、`docs/README.md`、`CHANGELOG.md`：依赖、配置和文档。

## 设计决策

- PostgreSQL 只保存业务关系、JSONB 元数据和雪花 ID；图片字节保存在阿里云 OSS。
- 认证依赖当前仍给出外部主体字符串，因此使用 `user_identities` 将其映射为内部雪花 `user_id`。
- `agent_id` 的外部 API 值仍是稳定代码；数据库列保存对应的静态雪花 ID。
- OSS 对象保持私有，通过应用内授权接口读取；不向前端返回公开 Bucket 地址。
- 旧数据库迁移与图片转存分开执行，避免应用启动时隐式改写已有数据。

## 潜在影响

- 已有数据库必须先备份，并按文档先转存 BYTEA 图片、再执行一次性 ID/表结构迁移；当前版本不能直接对旧 TEXT schema 自动启动。
- 同一部署中的并发后端进程必须配置不同的 `SNOWFLAKE_WORKER_ID`。
- 真实云端权限、Bucket 区域和凭据尚未验证；Bucket 需要保持私有，RAM 权限应限制到该 Bucket。
