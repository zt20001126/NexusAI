# 更新对话页面颜色体系

- 日期：2026-10-03
- 变更类型：其他
- 影响范围：前端对话页侧栏、顶部栏、欢迎页、消息、追问表单和输入区的颜色

## 背景

原有页面颜色直接散落在全局样式选择器中，包含深色侧栏和多处紫色强调色，与指定的浅灰蓝背景和蓝青品牌色体系不一致。

## 变更内容

- 在 `:root` 新增品牌色、背景、文字、边框和状态色 Design Tokens。
- 侧栏改为 `#F3F6FA`，页面使用浅色背景，内容区和卡片使用白色表面。
- 统一主次文字和边框颜色，并将 hover、active、焦点、状态和主要按钮调整为蓝灰及品牌蓝青色系。
- 移除组件表面明显阴影，侧栏与内容区通过浅色边框区分。
- 保留现有品牌 Logo 图像资源及页面布局和交互。

## 涉及文件

- `frontend/src/index.css`：定义全局 Design Tokens 并应用于对话页面样式。
- `CHANGELOG.md`：在 `[Unreleased]` 摘要中记录颜色体系调整。

## 设计决策

- 仅在 `:root` 定义颜色值；组件规则引用 tokens，便于后续统一调整主题。
- 错误状态保留文本语义，视觉上使用品牌蓝色系，避免引入页面中其他高饱和强调色。

## 测试与验证

- 命令：`npm run build`（在 `frontend/` 目录执行）
- 结果：通过；TypeScript 检查完成，Vite 生产构建成功。
