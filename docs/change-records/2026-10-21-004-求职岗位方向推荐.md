# 求职岗位方向推荐

- 日期：2026-10-21
- 变更类型：新功能
- 影响范围：求职助手对话、岗位方向推荐

## 背景

求职助手已有基础对话和结构化追问能力，用户希望根据求职者资料推荐适合的岗位方向，并让后续求职能力可以独立接入。

## 变更内容

- 新增求职资料、模型建议与校验结果模型，以及 `recommend_job_roles` 校验工具；岗位名称和理由由模型根据对话自主生成，生产代码不维护固定岗位目录。
- 在求职智能体工厂注册新工具，更新提示词，支持关键资料不足时先追问、资料足够后提交最多三个模型建议供工具校验。
- 年龄不能作为推荐依据；工具拒绝引用未提供资料的依据。模型无法提出可靠建议时返回受控结果，不生成实时招聘职位。
- 更新求职助手说明、智能体知识地图、接口文档和项目变更摘要。

## 涉及文件

- `backend/agents/job_agent/recommendation/`：输入输出模型及建议校验服务。
- `backend/agents/job_agent/tools/recommend_job_roles.py`、`backend/agents/job_agent/factory.py`、`backend/agents/job_agent/prompts/`：工具入口、注册与行为约束。
- `backend/tests/test_job_agent.py`：模型自由生成岗位、资料校验、工具返回和追问恢复测试。
- `backend/agents/job_agent/README.md`、`docs/项目知识地图.md`、`docs/接口文档.md`、`CHANGELOG.md`：同步能力边界。

## 设计决策

- 复用既有 LangGraph、Runner、Checkpoint、SSE 和追问协议；不新增数据库表或 HTTP 接口。
- 岗位方向由现有 Agent 模型节点生成；工具只校验结构和已声明的资料依据，不在工具内再次调用模型。其他求职能力可通过独立工具和工厂注册接入。
- 经验缺失时可使用现有四选一题卡；需要自由描述的专业和项目经历通过普通对话收集。

## 潜在影响

- 岗位由模型自主生成，推荐质量依赖模型对用户资料的理解；工具只校验结构与声明的资料字段是否存在，不能独立证明理由的语义真实性。
- 真实模型的提问与措辞可能因上下文不同而变化；离线测试验证了图内提问、恢复和推荐路径。
