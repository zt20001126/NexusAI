# 优化追问答案的聊天展示

- 日期：2026-10-19
- 变更类型：界面与接口
- 影响范围：恢复追问的消息历史数据和聊天答案气泡

## 背景

追问答案在消息中以 `field_id: answer` 的文本呈现，历史数据虽然保存了结构化答案，但没有对应题目标题，前端无法用商家看到的问题文字展示答案。

## 变更内容

- 恢复运行时把题目 ID 到标题的映射写入结构化追问答案块。
- 前端隐藏重复的原始 `field_id: answer` 文本，按题目标题分项展示回答；多选答案使用独立标签。
- 对既有消息中缺少标题的数据，将 snake_case 字段 ID 转成可读名称作为回退。
- 更新消息接口文档，并新增答案展示映射测试。

## 涉及文件

- `backend/agent/runner.py`、`backend/tests/test_api.py`：在恢复答案的持久化块中保存题目标题并验证接口内容。
- `frontend/src/features/chat/api/conversations.ts`、`frontend/src/features/chat/model/`、`frontend/src/features/chat/components/MessageList.tsx`、`frontend/src/index.css`：定义展示数据、格式化答案条目和答案卡片样式。
- `frontend/tests/questionAnswers.test.mjs`：验证题目标题、多选值和旧记录回退。
- `docs/接口说明.md`、`CHANGELOG.md`：同步消息数据说明和项目变更摘要。

## 设计决策

- 保留原有 `answers` 映射供运行时消费，同时附带 `question_titles` 供界面显示；不改变答案提交格式。
- 旧消息仍显示答案内容，标题缺失时使用人类可读的字段名回退。
