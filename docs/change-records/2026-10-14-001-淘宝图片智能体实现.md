# 实现淘宝电商图片智能体

- 日期：2026-10-14
- 变更类型：新功能 / 架构
- 影响范围：多智能体运行时、淘宝图片生成、聊天上传与展示、PostgreSQL 持久化、API 和数据库文档

## 背景

项目需要支持后续扩展多个独立智能体。本次按此前确定的方案新增淘宝电商图片智能体，支持商品主图和详情页图片生成、参数追问、参考图输入，并将各智能体的结果保存到同一张结果表。

## 变更内容

- 新增智能体注册机制和 `backend/agents/image_generation/` 实现目录，包含校验、对话、追问、结果处理节点及生成工具。
- 接入 TokenHub 混元生图接口；将上游临时图片下载后存为数据库字节，并通过受所有者校验的应用内路径读取。
- 新增智能体发现/对话/运行恢复/取消、图片上传和生成结果读取 API，同时保留默认智能体兼容路由。
- 增加共享 `task_results` 与参考图附件存储、会话/运行的 `agent_id` 隔离和数据库迁移。
- 更新聊天界面以选择智能体、上传参考图、提交追问答案并查看持久化的生成图片。
- 更新项目 README、架构说明、数据库结构说明和 API 接口文档；新增独立测试报告。

## 涉及文件

- `backend/agent/`：运行器、公共事件/Schema、工具注册和内存/PostgreSQL 持久化接口扩展。

- `backend/tests/test_api.py`、`backend/tests/test_image_agent.py`、`backend/tests/test_settings.py`：API、智能体、提供方适配与配置测试。
- `frontend/src/features/chat/`、`frontend/src/shared/api/http.ts`、`frontend/src/index.css`：智能体选择、图片上传和结果展示。
- `backend/.env.example`、`README.md`、`CHANGELOG.md`、`docs/架构说明.md`、`docs/数据库结构.md`、`docs/接口说明.md`、`docs/README.md`：配置与项目文档。
- `docs/test-reports/2026-10-14-011-淘宝图片智能体测试报告.md`：本任务测试报告。

## 设计决策

- 延续现有 `backend/agent/` 公共运行时代码，只新增 `backend/agents/` 下的具体智能体目录。
- 所有智能体使用统一 `task_results` 表，通过 `agent_id` 和 `result_type` 区分来源及结果类型。
- 参考图和生成图暂存在 PostgreSQL `BYTEA`，不接入 OSS；TokenHub 临时 URL 不作为持久结果链接保存。
- 追问参数以 TokenHub 接入文档为准，只询问缺失且由用户要求的参数；不引入 API 未定义的张数或独立清晰度字段。
- 新增按 `agent_id` 路由，同时保留已有默认智能体路由兼容旧客户端。
