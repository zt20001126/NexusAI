# Stripe 沙盒积分充值实施

- 日期：2026-10-23
- 变更类型：新功能
- 影响范围：登录账号积分充值、Stripe Checkout 沙盒支付、积分账本与充值状态查询

## 背景

用户需要在积分余额旁发起充值，按金额数字 1:1 获得积分，支持选择经配置验证的 Stripe 币种，并用沙盒银行卡测试支付。

## 变更内容

- 新增充值尝试表和 019 迁移，并允许积分明细记录正整数充值事件。
- 新增充值选项、Checkout 创建、本人状态查询与 Stripe Webhook API；Webhook 验签并校验沙盒模式、Session、金额和币种后，在同一数据库事务中幂等增加余额及账本明细。
- 新增前端充值弹窗、整数金额/币种校验、Stripe 跳转、支付返回状态及余额刷新。
- 增加测试密钥、Webhook 签名密钥、返回地址和币种金额范围配置；没有完整沙盒配置时充值保持关闭。
- 更新 README、接口/数据库/架构文档、项目知识地图、实现方案状态及 CHANGELOG。

## 设计决策

- 每次充值单独保存为有归属的尝试；以本地唯一事件键和事务保证重复 Webhook 不会重复入账。
- 浏览器成功回跳只查询状态，只有验签后的服务端支付事件可以增加积分。
- 币种使用服务端白名单，Stripe 最小货币单位换算遵循 Stripe 规则；ISK 和 UGX 保留 Stripe API 的两位小数兼容格式。
- 只接受 `sk_test_` 和 Webhook 签名配置；不接入真实支付密钥。
