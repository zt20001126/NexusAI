# 文献解读助手仅支持 PDF 上传

- 日期：2026-10-16
- 变更类型：功能调整
- 影响范围：文献解读助手的导入入口、异步入库、配置和相关文档

## 背景

产品范围调整为只通过上传 PDF 添加文献，不再提供公开链接或网页导入。

## 变更内容

- 移除前端链接输入框和链接导入 API 调用，仅保留 PDF 上传入口。
- 移除后端链接导入路由、请求 DTO、应用服务、URL 抓取器和 HTML 解析流程。
- 移除 URL 抓取及其重试配置；Worker 只从 OSS 读取 PDF 并处理。
- 更新 API、架构、数据库和实现方案文档。
- 保留数据库中的来源 URL 和旧来源类型，以便读取已有链接导入记录；新接口只创建 PDF 上传记录。

## 涉及文件

- `frontend/src/features/chat/components/LiteratureLibraryPanel.tsx`、`frontend/src/features/chat/api/literature.ts`、`frontend/src/index.css`：移除链接导入交互和请求。
- `backend/app/router/literature.py`、`backend/app/schemas/literature.py`、`backend/app/service/literature.py`：移除链接导入 HTTP 和业务流程。
- `backend/app/service/literature_tasks.py`、`backend/agents/literature_reader_agent/document_parser.py`、`backend/agents/literature_reader_agent/providers/`：移除链接抓取及 HTML 解析，仅保留 PDF 处理。
- `backend/app/crud/literature.py`、`backend/infra/settings.py`、`backend/.env.example`、`backend/requirements.txt`：清除不再使用的链接抓取持久化方法、设置和依赖。
- `backend/tests/test_literature_reader.py`：删除 URL 抓取和 HTML 解析相关测试。
- `docs/接口说明.md`、`docs/数据库结构.md`、`docs/架构说明.md`、`docs/agents/literature-reader/implementation-plan.md`、`CHANGELOG.md`：同步 PDF-only 范围与旧记录兼容说明。

## 设计决策

- 保留现有数据库来源字段和来源类型，避免删除已有记录或破坏既有网页来源回答；新建文献只接受 PDF 上传。
- 没有可读取 PDF 原件的历史待处理文献无法由新 Worker 重新入库，需重新上传 PDF。

- 已入库且已完成解析的链接来源文献继续可读；没有 OSS PDF 原件的旧待处理文献重新执行时会失败并提示重新上传 PDF。
