# 使用字符串枚举标识智能体

- 日期：2026-10-19
- 变更类型：架构
- 影响范围：后端智能体运行、PostgreSQL 会话与运行表、聊天 API 和前端聊天类型

## 背景

智能体曾使用独立雪花 ID，并在会话、运行和任务结果中重复保存。会话已经能够确定其智能体类型，不需要为智能体分配数据库 ID。

## 变更内容

- 新增 `AgentType` 字符串枚举，列出项目当前注册的七种智能体。
- 将会话、运行记录、Runner 状态、任务结果 API 和前端交互统一改用 `agent` 字段及枚举值；移除智能体雪花 ID 映射模块和固定通用智能体路由。
- 数据库会话表保存枚举字符串，运行和任务结果通过会话派生智能体类型。
- 新增 010 数据迁移，把已知会话智能体雪花值转换成字符串枚举，校验运行关系并删除重复字段。
- 将 API、数据库与架构文档同步到新字段，并释放 Snowflake worker 1022。

## 涉及文件

- `backend/agent/enums.py`：定义统一智能体枚举。
- `backend/app/models/`、`backend/app/crud/`、`backend/agent/`、`backend/agents/`：贯通枚举与会话派生逻辑。
- `backend/migrations/010_agent_type_strings.sql`：迁移现存数据结构和智能体值。
- `backend/app/router/agents.py`、`backend/bootstrap/`：移除旧固定路由并更新智能体路由。
- `frontend/src/features/chat/`：更新前端类型、请求和会话状态。
- `docs/接口说明.md`、`docs/数据库结构.md`、`docs/架构说明.md`、`CHANGELOG.md`：同步契约和变更记录。

## 设计决策

- API 破坏性移除 `agent_id` 名称和旧 `/api/agent/*` 固定路由；客户端需使用 `agent` 和 `/api/agents/{agent}/...`。
- 任务结果不保存 `agent`，通过所属会话读取；迁移要求先执行 009 任务结果表结构迁移。
- 迁移遇到未知智能体值或会话与运行的类型不匹配时中止，不猜测修复。
