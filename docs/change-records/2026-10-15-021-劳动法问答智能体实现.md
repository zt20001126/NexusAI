# 新增劳动法律 RAG 智能体

- 日期：2026-10-15
- 变更类型：新功能 / 架构
- 影响范围：后端智能体目录、聊天运行时、PostgreSQL + pgvector、劳动法律法规语料

## 背景

用户需要在现有 NexusAI 聊天项目中使用劳动法律 RAG。第一版范围为中国大陆全国性现行劳动法律法规，不新增管理员角色、管理页面或用户上传入口；法规语料放在劳动法律智能体目录中。

## 变更内容

- 新增劳动法律问答智能体并接入现有智能体注册表和通用聊天运行时，前端继续使用现有智能体选择入口。
- 新增法规 DOCX、PDF、Markdown、TXT 和 HTML 正文提取及按章、节、条切分；导入命令校验来源文件摘要并使用 TokenHub `kinfra-text-embedding-0.6b` 生成 1024 维 Embedding。
- 新增法规、版本和条文 ORM 表及 `004_legal_rag.sql`；保留历史版本，仅让一个当前有效版本参与查询；不再处于官方现行目录中的法规会在下一次同步导入后停用。
- 新增法条号/关键词检索、pgvector 余弦检索及倒数排序融合重排；模型回答逐条绑定检索证据 ID，后端校验引用范围后生成法条原文与官方链接。
- 检索依据不足时返回固定说明；检索或模型服务故障时返回独立故障提示，不将故障误报为“知识库依据不足”。
- 从国家法律法规数据库获取 14 部现行全国性劳动法律法规 DOCX 原件和 12 份 PDF 参考文件，保存在 `backend/agents/labor_law_agent/data/legal_corpus/source/`；导入清单指向 DOCX，并记录官方链接、版本日期和 SHA-256。
- 将 Compose PostgreSQL 镜像切换为 pgvector 镜像，并补充 Embedding 模型与检索配置；Embedding 复用现有 TokenHub API Key。
- 修复知识库仓储模块缺少 `Any` 导入导致后端启动失败的问题；重建本地后端并确认智能体发现接口已返回劳动法律问答。

## 设计决策

- 用户通过现有聊天页选择“劳动法律问答”并提问；法规文件由项目语料预置或由开发者同步导入，不开放普通用户上传接口。
- 首批语料从国家法律法规数据库当前标记为有效的全国性法律、行政法规中筛选 14 部劳动相关法规；该首批文件集是 MVP 起始语料，不声明覆盖所有劳动领域法规。
- 同目录的 PDF 是供人工查看的官方参考副本；`manifest.json` 只将每部法规的 DOCX 原件作为索引输入，避免同一法律重复入库。
- Embedding 使用 TokenHub OpenAI 兼容接口（`https://tokenhub.tencentmaas.com/v1`），模型固定为 `kinfra-text-embedding-0.6b`，输出 1024 维以匹配 `vector(1024)`；每批最多提交 128 条文本，更换向量维度时需要同步修改迁移、模型和重建索引。
- 为兼容 Kinfra 接口，关闭 LangChain 的 token ID 预处理，并显式使用 `encoding_format=float`。
- TokenHub Embedding 复用项目现有 `TENCENT_TOKENHUB_API_KEY`，不另设 API Key；若 Key 限定了访问范围，需授权 `kinfra-text-embedding-0.6b`。
- Rerank 使用关键词/向量倒数排序融合和确定性分数重排，不绑定未指定厂商的独立 Rerank 服务。
- 回答的法条号、原文和来源链接由服务端根据经校验的法条 ID 渲染，模型不能自行生成引用来源。

## 潜在影响

- PostgreSQL 服务必须安装 pgvector 扩展；Compose 已改用 `pgvector/pgvector:pg17`。生产环境部署时应确认数据库扩展和 `004_legal_rag.sql` 已应用。
- 入库和向量检索复用 `TENCENT_TOKENHUB_API_KEY`；TokenHub 控制台若将该 Key 限定到部分模型，需为其授权 `kinfra-text-embedding-0.6b`。未配置或未开通时仍允许应用启动，但无法完成向量入库。
- 向量列为 1024 维以匹配 Kinfra 输出；若其他环境已应用旧的 1536 维迁移或写入旧向量，需要迁移数据库结构并使用同一 Embedding 模型重建索引。
- TokenHub 的[向量模型文档](https://cloud.tencent.com/document/product/1823/133515)说明 `kinfra-text-embedding-0.6b` 固定输出 1024 维并兼容 OpenAI Embeddings API；调用需使用已开通模型的 TokenHub API Key。
- PDF 若为扫描图片且无法提取正文，当前解析器会拒绝导入并提示需要 OCR；首批语料使用官方 DOCX 原件进行文本解析。
- 首批法规来源已记录抓取日期；之后应重新同步官方版本并重新导入，不能据此声称语料永远实时。
