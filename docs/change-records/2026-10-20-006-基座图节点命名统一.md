# 基座图节点命名统一

- 日期：2026-10-20
- 变更类型：工程化
- 影响范围：`backend/agents/base_agent` 的 LangGraph 节点、图路由和基座说明文档

## 背景

基础智能体基座的输入处理、模型决策和输出节点使用了与统一命名约定不一致的名称。需要将四个核心节点统一为 `input_node`、`agent_node`、`tool_node` 和 `output_node`。

## 变更内容

- 将图节点 ID、节点实现模块和函数名称统一为新的节点名。
- 同步更新条件路由、图边和基座 README 中的节点流程与说明。
- 保留 LangGraph 内置 `ToolNode`、原有工具错误处理和节点业务逻辑。

## 涉及文件

- `backend/agents/base_agent/graph.py`：更新节点注册、路由名称和边连接。
- `backend/agents/base_agent/nodes/input_node.py`：承载原输入校验节点并统一工厂与节点函数命名。
- `backend/agents/base_agent/nodes/agent_node.py`：承载原模型对话节点并统一工厂与节点函数命名。
- `backend/agents/base_agent/nodes/tool_node.py`：更新返回模型决策节点的说明，继续使用 LangGraph 内置 `ToolNode`。
- `backend/agents/base_agent/nodes/output_node.py`：承载原回答节点并统一节点函数命名。
- `backend/agents/base_agent/README.md`：更新图流程、节点表和相关说明。
- `CHANGELOG.md`：补充 `[Unreleased]` 项目摘要。

## 设计决策

- 节点 ID、模块名和节点函数名使用同一组语义名称，降低图定义与实现之间的映射成本。
- 保留自定义模型后路由校验，以维持 AI 消息类型和已注册工具检查；工具执行继续复用 LangGraph 内置 `ToolNode`。

## 测试与验证

- 命令：在 `backend/` 执行 `.venv/Scripts/python.exe -m pytest -q`
- 结果：101 项通过，20 项失败。失败均因现有 `agent/persistence/memory.py` 中 `MemoryRunStore.claim()` 引用未定义的 `RunStatus`，未进入本次修改的节点逻辑。
- 命令：在 `backend/` 执行 `python -m compileall -q agents/base_agent`
- 结果：通过。
- 命令：使用 `backend/.venv/Scripts/python.exe` 执行临时基座图 smoke 脚本，以 `FakeListChatModel` 直接调用 `BaseAgent`。
- 结果：确认图包含四个新节点 ID 和预期边连接，直接调用返回预期回答。

## 潜在影响

- 尚待恢复的旧 Checkpoint 可能记录旧节点名；部署时应确认是否存在需要从旧图继续执行的待处理运行。
