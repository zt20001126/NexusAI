# 简历顶部信息展示调整

- 日期：2026-10-20
- 变更类型：功能
- 影响范围：简历助手基本信息编辑、在线 A4 预览、PDF 导出及简历 JSON 契约

## 背景

简历页首需要展示岗位、手动填写的工作经验年限、联系方式、手动填写的年龄和学历。出生年月不再用于展示或年龄计算。

## 变更内容

- 基本信息编辑器移除出生年月输入，新增手动年龄和工作经验年限整数输入。
- 在线预览和 PDF 第二行按求职意向、工作经验年限排序；第三行按手机号、邮箱、年龄、第一条非空学历排序。空项省略，不保留多余分隔符。
- 后端严格校验年龄为 0–120、工作经验年限为 0–80 的整数；API 不再接受 `birth_month`。
- 新增 JSONB 迁移以移除既有简历中的 `birth_month`，不从出生年月推算年龄。
- 更新接口、数据库和项目变更文档，并补充前后端摘要与数据兼容测试。

## 设计决策

- 年龄与工作经验年限都作为可空整数手动保存；不做日期计算，也不汇总工作经历月份。
- 学历取教育经历数组中第一条 `degree` 去除首尾空格后非空的记录。
- 迁移删除既有出生年月值，新增年龄和工作经验保持空值；迁移本身不在本次开发中执行。
- 在线预览读取当前草稿，PDF 继续读取已保存简历。
