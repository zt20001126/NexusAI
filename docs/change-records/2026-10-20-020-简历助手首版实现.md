# 简历助手首版实现

- 日期：2026-10-20
- 变更类型：新功能、架构、接口与数据模型
- 影响范围：智能体市场、简历编辑页面、简历 API、PostgreSQL、OSS 私有照片存储和 PDF 导出容器

## 背景

将在线简历编辑器方案落成智能体市场中的独立产品“简历助手”。首版仅供单人使用，不依赖外部身份系统；技能按字符串数组保存，并通过 Tiptap 纯文本编辑。

## 变更内容

- 在智能体目录加入“简历助手”入口，独立页面提供基本信息、教育、技能、工作和项目编辑、排版设置、A4 预览、保存和 PDF 导出。
- 增加受控简历 API、单人固定 owner、请求体大小限制、数据 Schema 校验、PostgreSQL JSONB 表和 013 迁移。
- 照片通过私有 OSS 暂存和正式对象保存，并处理上传/简历保存失败时的补偿清理。
- PDF 由 Chromium 生成，校验单页和内容溢出，并限制并发和超时。
- 将中文字体从大体积 Noto CJK 包调整为 Debian 的 `fonts-wqy-zenhei` 与 `fonts-arphic-ukai`，在界面和 PDF 中分别使用文泉驿正黑、文鼎 PL 中楷及回退字体。
- 同步 API、数据库、实现方案、CHANGELOG 和本任务记录；将 Compose 后端端口绑定在本机回环地址。

- `docs/接口文档.md`、`docs/数据库文档.md`、`docs/implementation-plans/2026-10-19-019-在线简历编辑器方案.md`、`CHANGELOG.md`：契约、方案与变更摘要。

## 设计决策

- 市场中的 Agent 卡片仍进入聊天流程；简历助手作为独立工具卡片打开编辑页面。
- 首版固定使用单人 owner，不接入外部身份系统；数据库仍通过 owner 唯一约束隔离资源。
- 技能以 `list[str]` 保存，Tiptap 仅编辑纯文本；工作和项目经历保留受限 Tiptap JSON。
- PDF 镜像安装体积较小的 Debian CJK 字体包。镜像构建确认两个字体包可安装，容器内 fontconfig 能解析目标字体。
