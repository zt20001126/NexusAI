# 整理劳动法律导入入口与架构路径

- 日期：2026-10-20
- 变更类型：架构
- 影响范围：劳动法律知识库离线导入命令、架构文档导航和分层说明

## 背景

劳动法律语料导入脚本位于业务 Agent 目录中，并直接组装应用 CRUD 与数据库适配器。架构文档中的图片 Agent 路径和普通业务数据目录也与当前实现不一致；架构文档的文件名与 README 导航约定不一致。

## 变更内容

- 将语料导入命令移至 `backend/scripts/ingest_labor_law_corpus.py`，领域导入逻辑仍由劳动法律 Agent 服务提供。
- 更新语料 README 中的导入命令。
- 将架构文档统一命名为 `docs/架构说明.md`，并修正图片 Agent 路径、应用分层说明及语料导入入口说明。
- 更新根目录 `CHANGELOG.md`。

## 涉及文件

- `backend/scripts/ingest_labor_law_corpus.py`：承载离线命令行组装入口。
- `backend/agents/labor_law_agent/data/legal_corpus/README.md`：更新运行命令。
- `docs/架构说明.md`：校正实际目录和层级职责。
- `CHANGELOG.md`：记录项目级摘要。

## 设计决策

- 将依赖 `app.crud` 和 `app.db` 的命令行组装放在 `backend/scripts/`；Agent 业务服务和存储协议保持在业务目录。
- 保留 `docs/架构说明.md` 作为固定名称，与文档命名规范及 README 导航一致。

## 测试与验证

- `git diff --check`：通过；Git 提示语料 README 的 LF 行尾在后续 Git 操作时可能转换为 CRLF。
- 静态路径检查：当前 README、AGENTS、后端代码和非历史文档中未发现旧导入模块路径、旧图片 Agent 路径、旧 `app/modules` 路径或旧架构文档文件名；历史变更记录保留当时路径。
- 自动化测试未运行：本次移动离线命令入口并修正文档，没有修改业务逻辑；本次未请求运行测试。
