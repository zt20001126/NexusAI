# 优化对话消息身份展示

- 日期：2026-10-03
- 变更类型：其他
- 影响范围：前端对话消息列表中的助手和用户身份展示

## 背景

对话列表中助手头像显示字母“N”，用户头像显示“我”，用户名称显示“你”，与品牌标志及清晰的身份标识不一致。

## 变更内容

- 助手消息头像改为使用现有 NexusAI 品牌图标。
- 用户消息增加渐变底色的个人头像图形，并将名称显示为“当前用户”。
- 调整两种头像的尺寸、边框和阴影样式。

## 涉及文件

- `frontend/src/components/MessageList.tsx`：使用品牌图标、用户头像图形和明确的用户名称。
- `frontend/src/index.css`：更新助手和用户头像样式。
- `CHANGELOG.md`：在 `[Unreleased]` 摘要中记录前端身份展示优化。

## 设计决策

- 用户数据中没有可用于显示的实际姓名，因此使用“当前用户”作为明确且不臆造姓名的标识。
- 助手头像复用 `frontend/public/brand/nexusai-icon.png`，保持品牌一致。

## 测试与验证

- 命令：`npm run build`（在 `frontend/` 目录执行）
- 结果：通过；TypeScript 检查完成，Vite 生产构建成功。
