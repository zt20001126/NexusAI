# 求职助手无关话题引导

- 日期：2026-10-21
- 变更类型：新功能
- 影响范围：求职助手对话行为

## 背景

求职助手需要在用户提出无关话题时说明职责并引导用户回到求职主题，同时保留现有求职相关能力。

## 变更内容

- 在系统提示词和 Agent 指令中定义求职职责范围，以及无关、问候和混合输入的回复规则。
- 无关话题要求直接用普通文字说明职责并引导用户提供求职信息；不调用题卡或岗位推荐工具。
- 更新求职助手说明、接口文档和项目变更摘要。

## 涉及文件

- `backend/agents/job_agent/prompts/system.md`、`prompts/agent.md`：增加职责范围与话题引导规则。
- `backend/tests/test_job_agent.py`：验证提示词边界与无关输入的直接回复路径。
- `backend/agents/job_agent/README.md`、`docs/接口文档.md`、`CHANGELOG.md`：同步用户可见行为。
- `docs/implementation-plans/2026-10-21-求职助手无关话题引导方案.md`：标记方案实施状态和完成条件。

## 设计决策

- 使用当前 Agent 模型结合对话语义判断，不新增固定关键词分类器、工具或图节点。
- 对混合请求优先处理求职部分；单纯问候时自然介绍职责。
- 真实模型分类仍可能误判边缘话题，提示词和离线测试不能替代真实模型抽样。
