# 求职助手简历不足分析触发策略

- 日期：2026-10-22
- 变更类型：新功能
- 影响范围：求职助手提示词、行为契约测试和能力文档

## 背景

求职助手已注册只读简历工具，但此前提示词没有规定用户要求分析本人简历不足时必须读取，模型可能直接给出缺少保存简历事实支持的分析。

## 变更内容

- 在系统提示词中规定本人简历不足分析须先调用一次无参数 `read_saved_resume`，并排除一般简历咨询和单纯片段润色。
- 在 Agent 提示词中补充语义触发规则、当前材料与保存版本的使用方式，以及 `found`、`not_found`、`unavailable` 的证据边界。
- 将简历工具链测试改为本人简历不足分析请求，并增加提示词契约断言。
- 更新求职助手 README 与根目录 CHANGELOG。

## 涉及文件

- `backend/agents/job_agent/prompts/system.md`：增加简历不足分析的读取要求。
- `backend/agents/job_agent/prompts/agent.md`：增加触发条件、排除情形和结果处理规则。
- `backend/tests/test_job_agent.py`：覆盖触发规则及工具调用场景。
- `backend/agents/job_agent/README.md`：说明简历读取的适用范围。
- `CHANGELOG.md`：记录用户可见行为变化。

## 设计决策

- 复用现有模型工具调用闭环，不增加确定性意图分类器；自然语言提示词是行为约束，不构成任意模型都必然遵守的代码级保证。
- 用户在诊断请求中同时提供简历材料时仍读取保存版本，并把当前明确提供的较新信息作为补充，区分两类信息。

## 测试与验证

- 命令：`python -m pytest -q tests/test_job_agent.py`（工作目录 `backend/`）
- 结果：未能收集测试；当前 Python 环境未安装 `langchain_core`，并提示 pytest 配置项 `asyncio_mode` 未识别。
- 命令：`git diff --check`
- 结果：通过；Git 仅提示工作区 LF 文件下次写入时可能转换为 CRLF。

## 潜在影响

- 符合条件的诊断请求会额外读取一次已保存简历；提示词不能提供程序级的强制调用保证。
