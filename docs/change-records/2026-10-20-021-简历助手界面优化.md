# 简历助手界面优化

- 日期：2026-10-20
- 变更类型：其他
- 影响范围：简历助手标题栏和左侧模块导航

## 背景

智能体市场中的简历助手卡片和简历页面标题栏使用文字标志，左侧导航底部显示了辅助说明卡片，模块入口和 A4 简历章节标题也缺少图标。

## 变更内容

- 智能体市场卡片和标题栏共用简历助手专属机器人头像，使用稳定 seed。
- 为基本信息、教育背景、专业技能、工作经历、项目经历和排版设置导航项增加语义化线性图标，并保留模块编号和选中状态。
- 为 A4 简历预览和导出 PDF 中的教育背景、专业技能、工作经历和项目经历标题增加对应图标。
- 移除左下角“边编辑边预览，保存后即可导出单页 PDF。”说明及对应样式。

## 涉及文件

- `frontend/src/features/chat/components/AgentAvatar.tsx`：改为调用共享机器人头像绘制器。
- `frontend/src/shared/components/RobotAvatar.tsx`：提供聊天和简历页面共用的机器人头像绘制器。
- `frontend/src/features/resume/ResumePage.tsx`：标题栏展示机器人头像。
- `frontend/src/features/chat/components/AgentDirectory.tsx`、`frontend/src/index.css`：市场卡片展示机器人头像并移除旧文字标志样式。
- `frontend/src/features/resume/components/ResumeSectionNavigation.tsx`、`ResumeSectionIcon.tsx`：增加模块图标。
- `frontend/src/features/resume/components/ResumePreview.tsx`、`ResumeSectionIcon.tsx`：在简历章节标题前展示图标。
- `frontend/src/features/resume/styles/resume.css`：调整头像和导航/章节图标布局，并清理说明卡片样式。
- `backend/app/service/resume_pdf.py`：在导出 PDF 的章节标题中渲染对应图标。
- `backend/tests/test_resume_pdf.py`：检查 PDF HTML 中章节图标的生成。
- `CHANGELOG.md`：记录未发布的界面变化。

## 设计决策

- 头像使用独立稳定 seed，沿用其他智能体的机器人头像风格，同时避免页面重新渲染时头像变化；绘制器放在 `shared` 供多个功能复用。
- 导航和章节图标使用语义化内联 SVG；屏幕预览和 PDF 使用相同的图形与颜色。
