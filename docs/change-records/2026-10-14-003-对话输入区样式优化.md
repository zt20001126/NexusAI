# 优化聊天输入框主题与交互

- 日期：2026-10-14
- 变更类型：界面改进
- 影响范围：聊天输入框、智能体选择、参考图按钮和发送/停止按钮

## 背景

用户反馈输入框主题和控件交互观感较弱，并明确要求选择器不显示“智能体”文字标签。

## 变更内容

- 移除选择器旁可见的文字标签，保留屏幕阅读器使用的无障碍名称。
- 将输入框收紧为清晰的输入行与工具栏层级，统一浅色表面、细边框和圆角控件。
- 柔化聚焦边框，增加选择器、附件、发送和停止按钮的悬停与键盘焦点反馈。
- 调整禁用发送按钮的颜色层级和输入提示文案对齐。

## 涉及文件

- `frontend/src/features/chat/components/Composer.tsx`：选择器改为图标入口，移除可见标签。
- `frontend/src/index.css`：调整输入框、工具栏、选择器和按钮的视觉与交互状态。
- `CHANGELOG.md`：记录未发布的界面变化。

## 设计决策

- 沿用现有蓝灰配色，不新增图标库或其他前端依赖。
- 选择器继续使用原生下拉列表，同时用自定义轻量样式弱化浏览器默认黑色焦点边框。

## 测试与验证

- 命令：在 `frontend` 目录运行 `npm run build`。
- 结果：TypeScript 检查和 Vite 生产构建通过；278 个模块构建完成。
- 命令：在仓库根目录运行 `git diff --check`。
- 结果：退出码 0，无空白错误；Git 提示部分工作区文件会按配置转换 LF/CRLF。

## 潜在影响

- 输入框垂直空间略有收紧；多行文本仍可按内容增长，参考图片预览区域不变。
