# 移除基座未使用请求状态

- 日期：2026-10-20
- 变更类型：工程化
- 影响范围：`backend/agents/base_agent` 的图状态及输入节点

## 背景

输入节点会把规范化请求写入 `BaseAgentState.original_request`，但基座内没有后续节点读取该字段，导致图状态保存了冗余数据。

## 变更内容

- 从 `BaseAgentState` 移除未使用的 `original_request` 字段。
- 输入节点保留用户消息类型、空内容和长度校验；校验通过后返回空状态更新。
- 更新 README 中输入节点的输出说明。

## 涉及文件

- `backend/agents/base_agent/state.py`：移除未使用的请求字段并修正文档字符串。
- `backend/agents/base_agent/nodes/input_node.py`：保留输入校验，不再写入请求文本。
- `backend/agents/base_agent/README.md`：说明输入节点仅校验，不额外写入状态。
- `CHANGELOG.md`：补充 `[Unreleased]` 项目摘要。

## 设计决策

- 保留输入节点，因为它负责验证直接图调用的用户消息；仅移除没有消费者的状态数据。

## 测试与验证

- 命令：在 `backend/` 执行 `.venv/Scripts/python.exe -m compileall -q agents/base_agent`
- 结果：通过。
- 命令：使用项目虚拟环境运行临时 smoke 脚本，验证有效输入返回空更新、空白输入仍被拒绝，以及基础智能体直接调用。
- 结果：通过。
- 未运行完整后端测试套件：本次只移除一个未使用的图状态字段，针对性 smoke 检查覆盖了输入校验和图调用路径。

## 潜在影响

- 旧 Checkpoint 可能仍保存此前写入的 `original_request` 值；当前基座没有读取者，新运行不再写入该字段。
