# 统一智能体追问数量上限

- 日期：2026-10-19
- 变更类型：新功能
- 影响范围：共享结构化追问协议、图片与 Listing 智能体、聊天前端及接口文档

## 背景

项目已限制单次运行最多追问 3 轮，但单轮题数上限仍为 5。现将所有结构化追问统一为每轮最多 3 道题、每次运行最多 3 轮。

## 变更内容

- 共享后端问题载荷、恢复答案 DTO 和前端协议常量统一限制每轮最多 3 道题；共享 Runner 继续限制每次运行最多 3 轮。
- 图片智能体最多一次提出 3 道待确认参数；超出的参数在后续轮次继续询问，并在恢复时保留已确认参数及尺寸确认状态。
- Listing 提示词、产品与技术设计文档、API 文档及 `[Unreleased]` 摘要同步更新为新规则。

## 涉及文件

- `backend/agent/constants.py`、`backend/agent/schemas/question.py`、`backend/app/schemas/agent.py`、`backend/agents/image_agent/schemas.py`：共享问题载荷、恢复答案 DTO 和图片追问 Schema 所用的每轮题数上限改为 3 道。
- `frontend/src/features/chat/constants.ts`：同步前端问题数量上限。
- `backend/agents/image_agent/state.py`、`backend/agents/image_agent/nodes/ask_node.py`、`backend/agents/image_agent/nodes/validation_node.py`：图片智能体分批提问、恢复时保留答案，并在新运行清除旧尺寸确认状态。
- `backend/agents/listing_agent/prompts.py`：提示模型遵守每轮 3 道、最多 3 轮。
- `backend/tests/test_question_limits.py`、`backend/tests/test_image_agent.py`、`backend/tests/test_runtime.py`：覆盖共享题数限制、图片参数分批与状态重置、第四轮拒绝。
- `docs/接口说明.md`、`docs/agents/listing/prd.md`、`docs/agents/listing/tdd.md`、`CHANGELOG.md`：同步协议说明。

## 设计决策

- 继续复用共享题目数量常量，避免不同智能体设置不一致。
- 图片参数按原有顺序组成批次；若待确认参数超过 3 项，未放入当前批次的问题在用户回答后继续提出。
