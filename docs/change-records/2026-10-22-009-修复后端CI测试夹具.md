# 修复后端 CI 测试夹具

- 日期：2026-10-22
- 变更类型：工程化
- 影响范围：后端 API、求职助手和简历优化相关自动化测试

## 背景

CI 后端测试因测试夹具未跟随邮箱认证、可信主体注入及简历优化写入器参数变化而失败。

## 变更内容

- API 测试夹具提供模拟认证服务，并为开发身份测试客户端设置模拟会话 Cookie；生产环境缺少会话的测试仍验证 401。
- 简历读取测试传入可信主体，并让测试读取器接收主体参数。
- 简历优化确认测试传入主体上下文，并按写入器的主体及候选参数签名配置回调。

## 涉及文件

- `backend/tests/test_api.py`：设置模拟认证服务与测试 Cookie。
- `backend/tests/test_job_agent.py`：同步简历读取测试主体参数。
- `backend/tests/test_job_resume_optimization.py`：同步确认节点上下文与写入器参数。
- `CHANGELOG.md`：在 `[Unreleased]` 汇总本次 CI 测试修复。

## 设计决策

- 保持生产认证及主体绑定行为不变，只更新测试夹具以模拟当前运行契约。
