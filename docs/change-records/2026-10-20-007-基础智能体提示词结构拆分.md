# 基础智能体提示词结构拆分

- 日期：2026-10-20
- 变更类型：工程化
- 影响范围：`backend/agents/base_agent` 默认对话提示词的维护与加载

## 背景

基础对话助手的默认提示词集中在 Python 常量中，不便将系统角色与 Agent 行为指令分开维护。需要采用独立 Markdown 提示词文件和加载器的结构。

## 变更内容

- 将系统角色提示词移至 `prompts/system.md`。
- 将交互规则和能力边界移至 `prompts/agent.md`。
- 新增 `prompts/loader.py`，按固定顺序读取并组合两个文件。
- 保留 `DEFAULT_CHAT_SYSTEM_PROMPT` 的公开名称及原提示词内容。
- 更新基座 README，说明提示词目录结构和加载方式。

## 涉及文件

- `backend/agents/base_agent/prompts/system.md`：定义基础助手身份。
- `backend/agents/base_agent/prompts/agent.md`：定义交流行为和能力约束。
- `backend/agents/base_agent/prompts/loader.py`：读取并组合 Markdown 提示词。
- `backend/agents/base_agent/prompts/__init__.py`：通过加载器生成并导出既有默认提示词常量。
- `backend/agents/base_agent/prompts/prompt.py`：移除被拆分的 Python 内嵌提示词。
- `backend/agents/base_agent/README.md`：更新提示词目录说明。
- `CHANGELOG.md`：补充 `[Unreleased]` 项目摘要。

## 设计决策

- 加载器在模块导入时读取 Markdown 文件并生成常量，调用方 API 和模型每轮接收的提示词格式保持不变。
- 提示词内容按原文本拆分，系统角色在前，Agent 行为指令在后。

## 测试与验证

- 命令：在 `backend/` 执行 `.venv/Scripts/python.exe -m compileall -q agents/base_agent/prompts`
- 结果：通过。
- 命令：使用项目虚拟环境运行临时 smoke 脚本，校验加载内容与两个 Markdown 文件的组合一致，并直接调用基础智能体。
- 结果：提示词组合和基础智能体直接调用均通过。
- 未运行完整后端测试套件：本次变更仅调整提示词资源和加载入口，使用针对性 smoke 检查覆盖了组合与调用路径。

## 潜在影响

- 默认提示词文件需与 Python 包源码一起提供；加载器在导入提示词包时会读取这两个文件。
