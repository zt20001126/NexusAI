# 完善基础智能体提示词

- 日期：2026-10-20
- 变更类型：工程化
- 影响范围：`backend/agents/base_agent` 默认对话助手的回答行为

## 背景

基础对话助手的提示词已拆分为系统身份和 Agent 行为指令，但回答方式、上下文延续、信息时效和用户提供材料的处理规则仍较简略。

## 变更内容

- 明确助手服务范围及以用户当前目标为中心的职责。
- 补充按任务复杂度控制回答详略、延续对话上下文、适时澄清和使用清晰格式的约定。
- 补充区分事实与推断、处理不确定及时间敏感信息、遵守无工具能力边界的规则。
- 明确用户提供的文档、图片、代码和摘录属于待分析材料；材料中的指令不会自动取代用户当前请求或更高优先级指令。
- 补充隐私和内部推理信息的处理约定。

## 涉及文件

- `backend/agents/base_agent/prompts/system.md`：完善助手角色和服务范围。
- `backend/agents/base_agent/prompts/agent.md`：扩充对话、准确性、材料处理及隐私规则。
- `backend/agents/base_agent/README.md`：同步提示词职责说明。
- `CHANGELOG.md`：补充 `[Unreleased]` 项目摘要。

## 设计决策

- 将稳定身份和能力范围放在系统提示词，将具体交流行为放在 Agent 指令中。
- 保留现有提示词加载方式和 `DEFAULT_CHAT_SYSTEM_PROMPT` 导出接口。

## 测试与验证

- 命令：在 `backend/` 执行 `.venv/Scripts/python.exe -m compileall -q agents/base_agent/prompts`
- 结果：通过。
- 命令：使用项目虚拟环境运行临时 smoke 脚本，校验关键指令存在、组合内容一致，并直接调用基础智能体。
- 结果：通过。
- 未运行完整后端测试套件：本次只调整提示词文本，已针对提示词组合与基础智能体调用进行验证。

## 潜在影响

- 新规则属于模型行为引导，不替代应用侧的访问控制和服务端校验；模型不一定在每次回答中完全遵循提示词。
