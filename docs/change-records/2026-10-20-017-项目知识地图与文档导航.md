# 项目知识地图与文档导航

- 日期：2026-10-20
- 变更类型：工程化、文档
- 影响范围：Codex 项目导航、根目录项目文档入口、架构文档导航

## 背景

项目已有架构、接口、数据库、开发约定和大量任务记录，但缺少一份按任务导航的全局知识地图。README 和架构说明中的接口、数据库文档链接仍指向旧文件名；README 的智能体清单未列出已注册的基础对话助手，文献助手说明仍包含已移除的网页导入能力。

## 变更内容

- 新增项目知识地图，汇总技术栈、主要依赖链路、7 个智能体的代码入口、按任务检索路径、文档责任和更新触发条件。
- 在 AGENTS.md 中增加知识地图入口和按任务选择文档的说明。
- 更新 README 文档导航，补齐基础对话助手，并将文献助手描述改为当前 PDF 导入能力。
- 修正 README 和架构说明中指向接口及数据库文档的失效链接，并从架构说明链接到知识地图。
- 在 CHANGELOG 的 `[Unreleased]` 区域记录知识地图和导航更新。
