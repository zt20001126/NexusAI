# 登录首页微交互优化

- 日期：2026-10-22
- 变更类型：其他
- 影响范围：首页智能体展示卡片与账号登录表单

## 背景

为首页卡片和登录表单补充轻量交互反馈，同时保持现有布局、文案与业务逻辑。

## 变更内容

- 智能体展示卡片悬停时轻微上浮，边框、背景和阴影平滑变化，头像轻微放大。
- 登录表单输入框聚焦时平滑显示既有蓝色边框与焦点环；按钮增加悬停、按下和键盘焦点反馈。
- 为新增过渡支持 `prefers-reduced-motion`。

## 涉及文件

- `frontend/src/features/home/home.css`：增加卡片和登录表单微交互样式。
- `CHANGELOG.md`：记录未发布的用户可见变化。

## 设计决策

- 仅使用现有 CSS 和原有组件，不改变展示卡片的语义或登录业务逻辑。
- 卡片与头像过渡时长为 220ms，按钮按压过渡为 140ms。
