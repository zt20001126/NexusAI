# 优化智能体选择菜单

- 日期：2026-10-14
- 变更类型：界面改进
- 影响范围：聊天输入框底部的智能体切换入口

## 背景

用户反馈浏览器原生智能体下拉面板与输入框主题不协调，展开后遮挡输入区域且视觉样式突兀。

## 变更内容

- 将原生 `<select>` 改为自定义菜单，菜单项展示助手名称、用途说明和当前选择状态。
- 触发器使用当前助手名称和图标；不显示“智能体”文字标签。
- 点击外部区域或按 Escape 关闭菜单；支持方向键、Home/End 和 Tab 键操作。
- 增加菜单弹出过渡、选中态、悬停态和键盘焦点样式。

## 涉及文件

- `frontend/src/features/chat/components/Composer.tsx`：实现菜单开关、选项选择、外部点击关闭和键盘操作。
- `frontend/src/index.css`：设置自定义菜单层级、选项卡片和响应式尺寸。
- `CHANGELOG.md`：记录未发布的界面变化。

## 设计决策

- 不增加 UI 依赖，使用现有助手名称和描述构建菜单项。
- 选中当前助手时关闭菜单，但不重置当前会话；切换到其他助手时仍由现有回调创建对应的新会话。

## 测试与验证

- 命令：在 `frontend` 目录运行 `npm run build`。
- 结果：TypeScript 检查和 Vite 生产构建通过；278 个模块构建完成。
- 命令：在仓库根目录运行 `git diff --check`。
- 结果：退出码 0，无空白错误；Git 提示部分工作区文件会按配置转换 LF/CRLF。

## 潜在影响

- 菜单项会显示注册表中的助手描述；窄屏下菜单宽度受视口限制。
