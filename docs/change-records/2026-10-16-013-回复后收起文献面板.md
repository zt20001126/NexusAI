# 模型回复后收起文献库面板

- 日期：2026-10-16
- 变更类型：其他
- 影响范围：文献解读助手聊天页面和文献库面板

## 背景

文献库面板固定显示在消息流上方，占据聊天区域空间，回答较长时会压缩模型回复的可视区域。

## 变更内容

- 最新一条助手消息出现正文或任务结果后，自动收起文献库面板。
- 收起状态显示横向长条按钮，展示已选文献数和展开箭头；点击后恢复完整面板。
- 完整面板标题栏也提供手动收起按钮。
- 切换会话时重置收起状态；加载到已有助手回复的历史会话时自动收起。

## 涉及文件

- `frontend/src/features/chat/ChatPage.tsx`：向文献库面板传递最新助手回复标识和发送状态。
- `frontend/src/features/chat/components/LiteratureLibraryPanel.tsx`：根据会话和助手回复变化控制自动收起，并提供展开与手动收起交互。
- `frontend/src/index.css`：增加收起长条、展开箭头、标题栏按钮和窄屏样式。
- `CHANGELOG.md`：补充未发布变更摘要。

## 设计决策

- 以最新助手消息的 ID 作为回复触发标识，正文或任务结果首次出现时收起；用户点击展开后，流式内容更新不会反复收起面板。
- 收起条仍保留在聊天内容流中，点击即可恢复面板。
