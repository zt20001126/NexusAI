# 项目文档

这里集中维护项目架构、数据结构和开发记录。项目启动方式与功能概览见根目录的 [README](../README.md)。

## 文档目录

| 文档 | 内容 | 适合在什么时候阅读 |
|---|---|---|
| [后端架构与扩展约定](ARCHITECTURE.md) | 后端分层、依赖方向和新增能力的放置规则 | 开始修改后端或智能体前 |
| [数据库结构说明](数据库表结构.md) | 应用表字段、关系、索引和 Checkpointer 存储范围 | 修改持久化代码或 SQL 前 |
| [任务级变更记录约定](changes/README.md) | 记录文件命名、内容模板和记录要求 | 开始重要变更或补充任务记录时 |
| [项目变更日志](../CHANGELOG.md) | 面向项目使用者的未发布与已发布变化 | 查看项目版本变化时 |

## 文档维护原则

- 根目录 `README.md` 说明项目用途、启动方式和常用开发入口。
- 架构文档说明代码职责与依赖方向；数据库文档说明当前实际使用的数据结构。
- `docs/changes/` 保存单项任务的背景、决策、文件和验证结果；`CHANGELOG.md` 只汇总面向使用者的变化。
- 文档描述以代码和实际验证结果为准。实现变化后，同步更新对应的说明，避免重复维护同一事实。
